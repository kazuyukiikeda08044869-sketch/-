## 配信コンテンツ計画（月4本）

### 第1週：ニュース×実務解説
```
タイトル形式：「【今週の会計ニュース】〇〇が変わる、実務への影響は？」
内容：その週の会計・税制ニュースを実務目線で解説
生成元：このリポジトリの news-hooks/ テンプレートを流用
所要時間：30〜45分（Claude生成 → 確認・加筆）
```

### 第2週：実務ノウハウ深掘り
```
タイトル形式：「現場で見た〇〇の失敗と、防ぐための具体策」
内容：ERP・会計システム導入の失敗パターンと対策
生成元：このリポジトリの threads/ テンプレートを流用
所要時間：30〜45分
```

### 第3週：テンプレート・チェックリスト
```
タイトル形式：「【テンプレ配布】〇〇で使える実務チェックリスト」
内容：月次決算・システム導入・棚卸など実務で使えるシート
所要時間：45〜60分（テンプレ作成が必要）
```

### 第4週：月次まとめ
```
タイトル形式：「今月の会計・ERP重要トピック 5選」
内容：その月の投稿を振り返り、重要ポイントをまとめ
生成元：月次まとめ投稿をメンバー向けに拡張
所要時間：20〜30分
```

**月の合計稼働：約2〜3時間**

## 無料記事との使い分け（導線設計）

```
X投稿（140字）
  └→ 「続きはnoteで」（無料記事・リード）
        └→ 「詳細・テンプレはメンバー限定」（有料メンバー記事）
```

### 具体例
```
X投稿：
「ERP導入が失敗する会社の共通点3選
① 要件定義をベンダーに丸投げ
② 現場担当者を巻き込まない
③ 移行データの検証を省略
→ 残り4パターンと対策はnoteに書きました（返信にリンク）」

↓ note無料記事（リード）：
「ERP導入失敗パターン7選」（失敗パターンのみ列挙・対策は有料）

↓ メンバー限定：
「ERP導入失敗パターン7選＋現場で使える回避チェックリスト付き」
```

## 立ち上げ時の目標人数の達成方法

### フォロワー数別の目標達成見通し

| Xフォロワー数 | 想定CV率 | 獲得人数 | 月収 |
|-------------|---------|---------|------|
| 500人 | 1% | 5人 | 4,900円 |
| 1,000人 | 1〜2% | 10〜20人 | 9,800〜19,600円 |
| 2,000人 | 1〜2% | 20〜40人 | 19,600〜39,200円 |
| 3,000人〜 | 1〜2% | 30〜60人 | 29,400〜58,800円 |

→ フォロワー2,000人超で月5万円が射程圏内。

### フォロワーが少ない場合の補強策

1. **初月限定価格を設定**（例：最初の10人は500円/月）
   - noteの「支援者プラン」機能を使う
2. **無料記事を先に3本公開**して「読んでくれている人」を増やす
3. **Xで「メンバー向け記事の一部」を無料公開**してサンプル体験させる
