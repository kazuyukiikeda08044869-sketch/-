# 投稿KPI・管理シート

## 月次目標（目安）

| 指標 | 目標値 | 備考 |
|------|--------|------|
| 月間インプレッション | 50万〜 | 週平均10〜15万を積み上げ |
| エンゲージメント率 | 3%以上 | いいね＋RT＋返信÷インプ |
| フォロワー増加 | +200〜500/月 | 良質コンテンツ継続で自然増 |
| 保存数の高い投稿 | 月3本以上 | 「あとで使える」系コンテンツ |

---

## 週次チェック項目

- [ ] 月〜金の投稿ができたか
- [ ] ニュース連動投稿を少なくとも1本出したか
- [ ] 返信・コメントに当日中に返信したか
- [ ] 高パフォーマンス投稿の型を記録したか

## 投稿カレンダー管理

```
毎週月曜：週次投稿案を作成
毎週金曜：パフォーマンス振り返り
毎月1日：月次まとめ投稿
```

---

## 参考：Xアルゴリズムのポイント（2025〜2026年版）

1. **返信数 > いいね数 > RT数** の順でランク評価されやすい
2. 外部リンクを含む投稿はリーチが下がる傾向（リンクは返信に貼る）
3. 長文テキストより「短文+スレッド」が拡散しやすい
4. 投稿後30〜60分の反応がその後のリーチを決める
5. Premium（旧Twitter Blue）ユーザーのRTは重み付けが高い
6. 毎日投稿しているアカウントが優遇される傾向
