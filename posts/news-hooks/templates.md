# ニュース連動投稿テンプレート集

ニュースが出たら2〜6時間以内にこのテンプレを使って投稿する。

---

## 型①：「ニュース → 会計的解釈」型

```
〇〇（ニュースの内容）というニュースが話題になってる。

これを会計側から見ると——

（会計・実務的な解説 2〜4行）

簿記では「〇〇の見方」を教えてくれない。
でも（まとめ・示唆）

これ、意外と知られてない。
```

**使いどころ：** 企業決算・M&A・金利・為替・税制

---

## 型②：「会社あるある × ニュース」型

```
〇〇のニュースを見て、うちの会社の話をする。

（具体的な体験談や実務エピソード）

外から見ると「大きな話」でも、
経理の現場では（リアルな影響）になって降ってくる。

簿記には載ってない話。
```

**使いどころ：** 増税・制度変更・不正事件

---

## 型③：「数字で語る」型

```
〇〇（ニュースの数字）という数字、
実は会計的にこういう意味がある。

・（ポイント1）
・（ポイント2）
・（ポイント3）

「なんとなく大きい」で終わらせてる人と、
「これはPL/BSにどう影響するか」まで読める人では
経営者からの信頼が全然違う。
```

**使いどころ：** 業績発表・市場データ

---

## 型④：「制度変更 速報」型

```
⚠️ 【会計実務に影響あり】

〇〇（制度・法律）が変わります。

影響を受けるのは：
・（対象者1）
・（対象者2）

やること：
1.（アクション1）
2.（アクション2）

期限：〇〇年〇月〇日

「知らなかった」では済まない話なので
お気に入り保存しておくのがおすすめ。
```

**使いどころ：** 電子帳簿保存法・インボイス・税制改正

---

## ニュースソース監視リスト

- 国税庁（改正情報）
- 金融庁（開示・会計基準）
- 日経電子版（企業決算）
- 日銀（金利・為替）
- 東京商工リサーチ（倒産・M&A）
