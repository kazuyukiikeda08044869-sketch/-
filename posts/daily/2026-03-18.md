## 投稿①「上場企業5年連続最高益」連動

**ソース：** 2026年3月期決算で上場企業の純利益が5年連続最高益更新見通し（当初の減益予想から一転）

```
上場企業が5年連続で最高益を更新しそうだ。

でも決算発表を経理視点で見ると、気になることがある。

「純利益が増えた」のに
「手元のキャッシュが全然増えていない会社」がある。

なぜか？

・設備投資に使った
・売掛金が増えた
・在庫が膨らんだ

利益とキャッシュは別物。
PLだけ見て「儲かってる」と判断してる社長、意外と多い。

簿記では「利益とキャッシュのズレ」を数式で教えてくれる。
でも「なぜズレるか」の実務感覚は、経験でしか身につかない。
```

## 投稿②「2026年度税制改正」連動

**ソース：** 令和8年度税制改正大綱閣議決定（基礎控除・給与所得控除の引上げ、2026年4月施行）

```
税制改正で「基礎控除が上がる」というニュース、
経理担当者には別の意味がある。

社員への影響→年末調整の計算が変わる
会社への影響→所得税の源泉徴収額が変わる

つまり「毎月の給与計算をやり直す必要がある」。

改正施行は2026年4月。
給与ソフトのアップデートが間に合わない場合、
手計算で修正することになる会社も出てくる。

「税制改正は政治の話」じゃなくて、
4月の給与計算に直撃する実務の話です。

担当者の方、今から確認しておいてください。
```

## 投稿③「インボイス制度改正」連動

**ソース：** 2026年10月から「2割特例」廃止・「3割特例」新設。仕入税額控除の経過措置も縮小へ

```
インボイスの「2割特例」、知ってますか？

消費税の申告を本来の計算ではなく
「売上税額の2割だけ納税すればOK」にする特例です。

これが2026年9月で終わります。

10月からは「3割特例」に変わるのですが——

怖いのはそこじゃない。

仕入税額控除の経過措置が
80% → 70% → 50% → 30% → 0%
と段階的に削られていく。

「インボイス、なんとなく対応した」で止まってる
フリーランスや個人事業主の方、
今年中に一度、税理士さんへの相談をおすすめします。

知らなかった、では済まないやつです。
```
