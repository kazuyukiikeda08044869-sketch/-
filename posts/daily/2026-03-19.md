## 投稿①「春闘2026 賃上げ発表」連動

**ソース：** ローソンが2026年4月から平均3.0%（月額8,319円）のベースアップを発表。日本郵政も4年連続ベースアップ（賃上げ率3.7%）を決定。（2026年3月19日）

```
簿記では教えてくれない、賃上げと経理部門の宿題

ローソンが今年4月から平均3%の賃上げを発表した。

社員には朗報。経理部門には作業が積み重なる。

賃上げが決まった瞬間に動き出すこと：

・社会保険料の会社負担分が増える（給与の約15%が法定福利費として計上）
・賞与引当金の積み立て額を見直す
・退職給付費用の計算も再試算が走る

※賞与引当金：半年後に払う賞与を、毎月少しずつ費用として積んでおく処理。
　決算をまたぐ支払いに備えるために存在する。

簿記では「給料 ／ 現金・預金」と1行で習う。
でも実務では、基本給が1円変わっただけで社会保険・引当金・予算の数字が連鎖する。

「賃上げは人事の話」と思ってると、4月の給与計算で手が止まる。
```

## 投稿②「SAP 2027年問題」連動

**ソース：** SAP ECC 6.0の標準保守が2027年末に終了。日本のSAP導入約2,000社がS/4HANAまたはクラウド型ERPへの移行を迫られている。

```
簿記では教えてくれないERP移行費用の正体

SAPのサポートが2027年末に終わる。
日本だけで約2,000社が、移行を迫られている。

話題になるのは「費用が高い」という点ばかりだが、
経理部門には別の問題がある。

「この費用、どう会計処理するか」だ。

ERP移行で発生する費用の例：
・コンサル費用
・データ移行費用
・アドオン開発費
・社内担当者の工数

オンプレ型を導入した場合 → 無形固定資産に計上、5年で償却。
クラウド型（SaaS）に切り替えた場合 → 資産計上できない、毎期の費用処理。

同じ「ERP入れた」でも、BSへの影響がまったく違う。

簿記では「ソフトウェア償却」を習う。
でも「クラウド型は資産にならない」は、経営者にもあまり知られていない。

移行の意思決定をする前に、財務インパクトを試算しているか。
そこが経理の腕の見せどころだと思う。
```
