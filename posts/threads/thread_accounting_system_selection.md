# スレッド投稿案：「会計システムの選び方、誰も教えてくれない本音」

---

## ツイート1（フック）

```
「どの会計ソフト使えばいいですか？」

この質問、毎月何十回も聞かれる。

でも正直に答えると——
「ソフトより先に決めることがある」

🧵会計システム選定の本音を書く。
```

---

## ツイート2

```
まず聞く質問はこれ。

「今、月次決算を何日で締めてますか？」

・20日以上→システムより業務フロー改善が先
・10〜15日→ソフトで改善できる余地がある
・5日以内→今のシステムで十分かも

ソフトを変えても、業務が変わらなければ締め日は変わらない。
```

---

## ツイート3

```
次に聞くのはこれ。

「何人で経理をやっていますか？」

1〜2名→クラウド会計（freee/MFクラウド）で十分
3〜10名→中堅パッケージ（PCA/勘定奉行）を検討
10名以上→ERPを視野に入れる

「みんなが使ってる」は選定基準にならない。
規模と体制で選ぶ。
```

---

## ツイート4

```
クラウド会計のメリット・デメリット、
正直に言う。

【メリット】
・初期費用が安い
・自動連携が便利（銀行・カード・レシート）
・どこでもアクセスできる

【デメリット】
・カスタマイズが難しい
・複雑な原価計算には向かない
・データが外に出ることへの不安

「便利」と「自社に合う」は別の話。
```

---

## ツイート5

```
オンプレミスとクラウド、どっちがいいか。

2026年時点での正直な見解：

・スタートアップ・中小企業→クラウド一択に近い
・製造業・複雑な原価管理が必要→オンプレか専用システム
・グローバル展開→クラウドERP（SAP BTP等）

「クラウド=新しい=良い」じゃない。
業務要件に合うかどうかで選ぶ。
```

---

## ツイート6

```
システム選定で絶対やってほしいこと。

「デモ環境で自社の仕訳を入れてみる」

カタログスペックじゃわからない。
実際に：
・よく使う仕訳が入れやすいか
・承認フローが自社に合うか
・レポートが経営者に見せられる形か

これを試さずに契約したら後悔する。
```

---

## ツイート7（まとめ）

```
会計システム選定のチェックリスト：

□ 月次決算の締め日を確認した
□ 経理人数・体制に合うか確認した
□ デモで自社の仕訳を試した
□ 5年後の会社規模を想定した
□ 導入後のサポート体制を確認した
□ 「なんとなく有名だから」で選んでいない

簿記では「システム選定」を教えてくれない。
でもこれが経理の実務で一番大事な判断の一つ。
```
