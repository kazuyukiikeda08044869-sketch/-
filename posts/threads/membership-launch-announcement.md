# メンバーシップ開始告知 投稿セット

## 投稿①：メイン告知（スレッド形式）

```

noteでメンバーシップを始めます。

「Xに書ききれない実務の話」を
毎週メンバー限定でお届けします。

```

```
お届けする内容：

📌 週1本：会計・ERP実務の深掘り解説
📌 月1本：今月の重要トピックまとめ
📌 実務テンプレート・チェックリスト配布
📌 Xでは書けなかったぶっちゃけ話

「簿記では教えてくれない話」の有料版です
```

### 3ツイート目（誰向けか）
```
こんな方に読んでほしい：

✅ 経理・会計事務所で働いている
✅ ERP・会計システム導入に関わっている
✅ 経営管理・財務に携わっている
✅ 実務で使える情報がほしい

教科書や研修では得られない
「現場の知識」を届けます
```

